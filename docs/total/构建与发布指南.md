# 构建与发布指南

> 日期：2026-08-23 ｜ 发布策略：发布包**永远为 Rust 版**（costcut-infer.exe）；Python 版仅技术探索。

## 1. 一键构建 + 打包（build.sh）

项目根执行 `./build.sh`——一条命令完成全流程：

```
[1/5] Rust release 构建      cargo build --release（rust/）
[2/5] 部署 v0.1.0_beta       exe + 依赖 dll → produce/v0.1.0_beta/
[3/5] Inno Setup 打包        produce/Inno.iss → setup/（ISCC.exe 自动检测）
[4/5] 冒烟测试               v0.1.0_beta/costcut-infer.exe --smoke
[5/5] 完成                   列出 setup/ 安装包
```

## 2. 产物结构

```
produce/
  Inno.iss              # Inno Setup 打包脚本（modern wizard + lzma/solid）
  v0.1.0_beta/          # 发布打包源（costcut-infer.exe——dll 由 build.sh 复制）
setup/
  CostCutInfer-0.1.0_beta-setup.exe   # 安装包（约 51MB）
```

## 3. 安装包内容

- `costcut-infer.exe` + 依赖 dll（torch_cpu/c10/fbgemm/asmjit/libiomp5md 等）安装到 `C:\Program Files\CostCutInfer`
- 开始菜单 + 桌面图标（可选）——安装后启动
- 依赖：Inno Setup 6（`ISCC.exe`——用户路径 `AppData/Local/Programs/Inno Setup 6/`）

## 4. 版本与仓库

- 大 dll（>100MB——torch_cpu 等）**不入库**（.gitignore 排除——由 build.sh 从 rust/target 复制）
- 版本：v0.1.0_beta（AppVersion——produce/Inno.iss 中配置——OutputBaseFilename 含版本号）
- 手动打包（无 build.sh）：`ISCC.exe produce/Inno.iss`——输出到 setup/

详细架构见根 README；性能数据见 `性能测试汇总.md`。
