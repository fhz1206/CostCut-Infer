# 推荐配置指南（CPU / GPU / NPU）

> 日期：2026-08-19 ｜ 对象：CostCut Infer（Python liteengine——engine.toml 的 `[device]` 推荐配置）
> 原则：**实测驱动**——本机 12GB CPU-only 笔记本实测部分优化为负收益（默认关）；GPU/NPU 为理论推荐方向（未实测）。

## 1. 设备推荐配置（engine.toml `[device]`）

| kind | 设备场景 | threads | fp16 | fused_matmul | expert_parallel | 说明 |
|---|---|---|---|---|---|---|
| `cpu` | 12GB CPU-only 笔记本（默认） | 物理核数（0=自动） | `false` | `false`（真实转置适配后开） | `false`（本机实测慢 ~5x） | 本机实测基准 |
| `gpu` | NVIDIA/AMD 独显 | 0（torch 管理） | `true` | `true` | `true` | 显存够时最大并行 |
| `npu` | 昇腾/寒武纪等 NPU | 0 | `true` | `true` | `true` | 异构算力 |

## 2. 优化开关说明（`[inference]`）

| 开关 | CPU 推荐 | GPU/NPU 推荐 | 说明 |
|---|---|---|---|
| `compute_dtype` | `fp32` | `fp16` | 计算精度——CPU fp32 实测最优；GPU/NPU fp16 快 |
| `int4_fused_matmul` | `false` | `true` | T-MAC 风格融合 matmul——合成 [out,in] 实测 **1.89x**；真实 [in,out] 转置适配为后续 |
| `expert_parallel` | `false` | `true` | 专家多线程并行——本机 BLAS 竞争实测慢；多核/异构可受益 |
| `speculate` | 默认 `false`（/speculate 切换） | `false` | 投机解码——接受公式已对齐；K 选择调优为后续 |

## 3. 配置示例

### CPU（12GB 笔记本——默认）
```toml
[device]
kind = "cpu"
threads = 8          # 物理核数（0 = 自动）
fp16 = false
fused_matmul = false
expert_parallel = false
```

### GPU
```toml
[device]
kind = "gpu"
threads = 0          # 由 torch 管理
fp16 = true
fused_matmul = true
expert_parallel = true
```

### NPU（昇腾/寒武纪等）
```toml
[device]
kind = "npu"
threads = 0
fp16 = true
fused_matmul = true
expert_parallel = true
```

## 4. 说明与限制

1. **本机 CPU 实测**：朴素融合/专家并行/投机均为负收益——默认关（`[device]` 推荐值随 kind 切换，可覆盖）。
2. **真实模型转置适配**：真实专家权重为 `[in, out]` 转置存储——`_matmul_int4_fused` 的 z/scales 转置适配为后续——CPU 的 `fused_matmul` 待适配后开启。
3. **GPU/NPU 未实测**——推荐值为理论方向（fp16/fused/并行在 GPU/NPU 上通常收益显著）；接入后需实测校准。
4. `threads` 与 torch 的线程管理：GPU/NPU 场景建议 0（由 torch/BLAS 管理），避免线程竞争。
