## 2. 基准对比（matmul 内核实证）

| 项 | 数据 | 结论 |
|---|---|---|
| 512³ matmul | serial 24.19ms / 并行 12.53ms（1.90x）/ AVX2 1.21x / tch BLAS 130ms（0.14x） | BLAS 转换开销无收益——已回退 |
| 2048² matmul | 标量 0.11s ≈ tch BLAS 0.11s（0.99x） | 转换抵消优势——无收益 |
| 合成 prefill matmul（3x64） | Python 19.48ms vs Rust 0.5ms | **Rust 大幅领先** |
| Q4 融合内核（matmul_awq_fused） | 56.4ms vs 反量化+matmul 52ms（0.92x） | 按行融合慢——保留待 SIMD 优化 |
| 反量化并行化 | 1 层构造 280s → **~20s** | 8 线程专家并行 |

## 4. 当前优化状态

1. **已实现**：反量化并行化（构造 280s→20s）、matmul 行并行（m≥64）、KV 缓存续接（generate + 投机）、转置权重（gate_up_t + lm_head_t 列连续）、**lm_head 预转置（~8x）**、完整 YaRN（Python）、linear_blas（参考 PyTorch addmm）。
2. **已突破**：**lm_head 预转置（~8x——0.48s/token）**——剩余瓶颈：61 层完整模型的 decode（attn 0.35s/层 × 61——每层前向）。
3. **参考项目路径**：llama.cpp 的 Q4 反量化→matmul 融合打包内核（vec_dot SIMD——唯一正解）+ 转置权重（61 层完整模型验证）。
