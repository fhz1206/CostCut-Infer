# 性能测试汇总报告

> 日期：2026-08-19 ｜ 对象：CostCut Infer（Python liteengine + Rust costcut-infer）｜ 环境：12GB CPU-only 笔记本（torch 4 线程；Rust release——64 位 mingw-w64 GCC 15.3 + tch/libtorch 2.11.0）
> 本文件整合原：`性能分析报告.md` + `Rust版本性能测试报告.md`（已并入——原文件删除）

## 1. 实测数据总览

| 项 | Python（torch 4 线程） | Rust（GCC 15.3 + tch） | 胜者 |
|---|---|---|---|
| 合成 prefill matmul（3x64） | 19.48ms | 0.5ms（3 token generate） | **Rust 大幅领先** |
| 512³ matmul | **4.88ms（BLAS）** | serial 23.8ms / 并行 12.5ms / tch BLAS 108ms | **Python BLAS 快 2-5x** |
| 真实模型 decode | **36.08 s/token（40 层）** | 1 层标量反量化 280s 超时（P0） | Python 完整运行 |

## 2. Rust 冒烟明细（--smoke）

| 环节 | 结果 |
|---|---|
| M1 加载/反量化 | 多分片 95427 项 + AWQ max_abs=0.1282 + 权重前缀 6/6 |
| M3 合成 generate | **0.5ms** |
| M4 并行 matmul（512³） | serial 23.8ms vs 并行 12.5ms——**1.90x** |
| M4 AVX2/FMA | 1.01x（波动——64 位编译器曾测 1.25x） |
| M4 分块缓存 | 0.17x（负收益） |
| **matmul_blas（tch BLAS）** | 512³ **108ms（0.22x——转换开销大）**——结果一致 ✓ |

## 3. Python 明细（重测）

| 项 | 结果 |
|---|---|
| 合成 matmul（3x64） | 19.48ms（torch 调用开销） |
| 512³ BLAS matmul | **4.88ms** |

## 4. 结论

1. **编译器/依赖进展**：64 位 GCC 15.3 显著提升（并行曾测 2.48x、AVX2 1.25x 转正）；tch/libtorch 2.11.0 编译成功（C1083/D9002 解决）。
2. **BLAS 接入验证**：matmul_blas 结果一致 ✓——但 512³ 转换开销大（108ms vs 标量 23.8ms）——**大矩阵（真实模型规模）才有优势**。
3. **核心 P0**：真实模型端到端（标量反量化 1 层 280s 超时）+ BLAS 大规模验证。
